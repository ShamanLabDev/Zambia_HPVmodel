# Required input files 

- `Pop_1990.xlsx`: numeric Women/Men columns, 17 rows for ages 0–4 through 80–84.
  Required by the calibration grid and the projection script's single calibration
  simulation, which generates the initial agent pool.
- `ageprofile.mat`: numeric age19F/age19M vectors, 17 five-year age-band counts.
  Required by the forward projection model; row and column vectors are supported.
